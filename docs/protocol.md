# GZFV gaze packet (v1)

One UDP datagram per tracker frame, 92 bytes, little-endian. Same framing idea as insight-vio's
`IVIO` pose packet (magic, version, flags, sequence, timestamp, payload, CRC-32), so one receiver can
demultiplex head pose and gaze by magic.

| offset | size | type | field |
|---:|---:|---|---|
| 0 | 4 | char[4] | magic `GZFV` |
| 4 | 2 | u16 | version = 1 |
| 6 | 2 | u16 | flags: bit0 gaze valid, bit1 left valid, bit2 right valid, bit3 user-calibrated, bit4 saccade, bit5 OpenXR axes |
| 8 | 4 | u32 | sequence number |
| 12 | 8 | u64 | timestamp, ns, middle of the camera exposure (camera clock) |
| 20 | 12 | f32[3] | combined gaze origin, mm, headset frame |
| 32 | 12 | f32[3] | combined gaze direction, unit vector |
| 44 | 8 | f32[2] | gaze point on the display, NDC (x right, y up, [−1, 1]) |
| 52 | 16 | f32[4] | left eye: pupil diameter mm, confidence 0–1, yaw deg, pitch deg |
| 68 | 16 | f32[4] | right eye: same |
| 84 | 4 | f32 | expected angular error, deg (p95 from calibration validation) |
| 88 | 4 | u32 | CRC-32 (zlib polynomial) of bytes 0–87 |

Headset frame: +X right, +Y up, +Z towards the display. With bit5 set, vectors are in OpenXR view
space (Z flipped). The renderer only needs `ndc`, `flags` and `error_deg`; the 3D ray is there for
engines that do their own projection (e.g. per-eye asymmetric XR frusta).

## Implementations

| side | file | tests |
|---|---|---|
| Python sender/receiver | `gazefov/protocol.py` (`GazeSender`, `receive_forever`) | `tests/test_protocol_safety.py` (golden vector, CRC, UDP loopback) |
| TypeScript decoder/encoder | `render/src/gaze/protocol.ts` | `render/tests/unit.test.ts` (same golden vector, byte-identical re-encode) |
| UDP → WebSocket relay | `render/scripts/relay.ts` (hand-written RFC 6455 server) | accept-key and framing tests |
| browser client | `render/src/gaze/source.ts` (`WebSocketGazeSource`) | — |

The golden vector `tests/fixtures/gaze_packet_v1.json` is generated by
`scripts/make_protocol_fixture.py`; both languages must decode it and re-encode it to the same bytes.

## Wiring

```text
tracker (python) --UDP:5566--> relay (node) --ws://127.0.0.1:8766--> renderer (browser / Vanta host)
```

```bash
cd render && npm run relay                     # udp 5566 -> ws 8766, localhost only
python -c "from gazefov.protocol import GazeSender; s=GazeSender(); s.send(0,[0,0,0],[0,0,1],[0.2,0.1])"
# demo page: npm run build && npx vite preview, open /?ws=ws://127.0.0.1:8766
```

Checked end to end on the development machine (2026-11-26): `GazeSender` → relay → a Node
`WebSocket` client received the 92-byte packets unchanged.

Security: packets are unauthenticated; both ends bind to localhost by default. Only bind to a LAN
address on a trusted network.

## Smoothing

`render/src/gaze/filter.ts` applies a 1€ filter (Casiez et al. 2012) per angle and an I-VT saccade
flag (> 100°/s, Salvucci & Goldberg 2000). During a flagged saccade the Vanta driver widens the
fovea by `saccadeExtraDeg` (default 5°).
